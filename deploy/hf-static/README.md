# SIRIN UI Demo

An interactive, offline replay of verified SIRIN artifacts for contextual-inconsistency inspection.

Choose a recorded LongMemEval case to inspect decisive evidence, the recorded response, its uncertainty or sequence score visualization, and run provenance. This public demo does not load model weights, call external APIs, or accept user data.

For the complete project and live UI workflow, see the [SIRIN repository](https://github.com/sb-ai-lab/SIRIN).
